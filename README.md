# KAALVEYR — Personal Ascension System

Your supreme AI overseer, strategist, and personal evolution system.

## Deploy to GitHub Pages

1. Upload all files to your GitHub repo
2. Go to Settings → Pages → Deploy from main branch
3. Your app will be live at: `https://YOURUSERNAME.github.io/kaalveyr`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main app (rename from kaalveyr.html) |
| `manifest.json` | PWA install config |
| `sw.js` | Service worker (offline support) |
| `icon-192.png` | App icon (add your own) |
| `icon-512.png` | App icon large (add your own) |

## Install as App

**Laptop (Chrome):** Visit URL → click install icon in address bar → Install

**Phone (Android):** Visit URL in Chrome → 3-dot menu → Add to Home Screen

**Phone (iPhone):** Visit URL in Safari → Share button → Add to Home Screen

## Features

- XP & Rank system (Initiate → Eternal Strategos)
- Full task tracker across all life domains
- Kaalveyr AI powered by Claude (voice in + voice out)
- Live discipline, lock-in & momentum scores
- Works offline after first load
